# КРАТКОЕ РЕЗЮМЕ: Как система определяет доступность спутников

## Главный ответ на вопрос: "Как они понимают, дотягиваются ли они или нет?"

### Одно простое правило:

```
ЕСЛИ (расстояние от getter'а до спутника) ≤ 7000 км
   → спутник ✓ ДОСТУПЕН
ИНАЧЕ
   → спутник ✗ НЕ ДОСТУПЕН
```

## Как рассчитывается расстояние?

### Формула в три шага:

```
1️⃣  Расстояние по поверхности Земли (Haversine)
    Это дугообразное расстояние между двумя точками на глобусе
    Пример: Tokyo → Osaka = ~380 км

2️⃣  Добавляем высоту спутника
    Спутник Starlink летит на высоте 550 км над поверхностью
    Луч идет НЕ по земле, а в космосе!

3️⃣  Используем теорему Пифагора
    total = √(расстояние_по_земле² + высота_спутника²)
```

### Реальный пример:

```
Tokyo (139.76°E, 35.68°N) → Спутник (120.5°E, 40.2°N)

ШАГ 1:
  Разница: 19.26° по долготе, 4.52° по широте
  По Haversine: ~2236 км по земной поверхности

ШАГ 2:
  Спутник летит на 550 км выше поверхности

ШАГ 3:
  total = √(2236² + 550²) = √(5000096 + 302500) = 2302.7 км

РЕЗУЛЬТАТ:
  2302.7 км ≤ 7000 км → ✓ ДОСТУПЕН
```

## Как проверить в браузере?

### 3 легких шага:

```
1. Нажмите F12 (открыть консоль браузера)

2. Загрузите JSON с getter'ами

3. Смотрите логи типа:
   "STARLINK-1019": G1:✓ 2302km | G2:✗ 3800km
   
   Это означает:
   - Getter1 может дотянуться (2302 км < 7000 км) ✓
   - Getter2 не может (3800 км > 7000 км) ✗
```

## Приоритет выбора спутника

### Если есть спутник, до которого могут дотянуться ОБА getter'а:

```
Getter1 → STARLINK-1020 ←  Getter2
  (оба рейкастят в один спутник)
```

Система выбирает ТОЛЬКО такие спутники и игнорирует все остальные.

### Если такого нет, каждый выбирает свой ближайший:

```
Getter1 → STARLINK-1019     STARLINK-1021 ← Getter2
```

## Что вы видите в консоли

### Заголовок пары:
```
[updateRaysForGetterPairs] ===== PAIR: japan_pair =====
[updateRaysForGetterPairs] Getter1: "Tokyo" at (139.76, 35.68)
[updateRaysForGetterPairs] Getter2: "Osaka" at (135.50, 34.73)
[updateRaysForGetterPairs] Max distance: 7000km
```

### Каждый спутник:
```
"STARLINK-1019": G1:✓ 2302km | G2:✗ 3800km
"STARLINK-1020": G1:✓ 2300km | G2:✓ 1600km
```

Расшифровка:
- `G1:✓ 2302km` = Getter1 может дотянуться, расстояние 2302км
- `G2:✗ 3800km` = Getter2 не может, расстояние > 7000км

### Итоги:
```
[updateRaysForGetterPairs] Processed: 2500 satellites, Accessible: 147
[updateRaysForGetterPairs] Common: 5, G1 only: 50, G2 only: 45
```

Означает:
- Всего спутников: 2500
- Доступны для хотя бы одного: 147
- Доступны для ОБОИХ: 5
- Доступны только для Tokyo: 50
- Доступны только для Osaka: 45

## На карте

### Если найдены ОБЩИЕ спутники:
```
✓ Вы видите цветные линии от ОБОИХ getter'ов к спутникам
  - Зеленые = близко (< 3500 км)
  - Желтые = средне (3500-5500 км)  
  - Красные = далеко (5500-7000 км)
```

### Если спутников нет:
```
✗ Нет линий
  Причины:
  - Getter'ы слишком далеко друг от друга (> 8000 км)
  - Getter'ы в полюсах (мало спутников)
  - Все спутники за 7000 км
```

## Почему нужна формула с высотой?

### Без учета высоты (НЕПРАВИЛЬНО):
```
Tokyo → Спутник = только горизонтальное расстояние 2236км
ОШИБКА: спутник летит в небе на 550км!
```

### С учетом высоты (ПРАВИЛЬНО):
```
Tokyo → Спутник = √(2236² + 550²) = 2302км
ПРАВИЛЬНО: луч идет в 3D пространстве
```
