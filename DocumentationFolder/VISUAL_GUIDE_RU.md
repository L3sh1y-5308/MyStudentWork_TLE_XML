# Визуальное руководство: Как работают пары Getter'ов

## Концепция

```
Обычный режим (старый):
┌─────────────┐
│  Getter 1   │────────┐
└─────────────┘        │
                       ├──> Ближайшие 10 спутников
┌─────────────┐        │    (любые в радиусе 5000 км)
│  Getter 2   │────────┘
└─────────────┘

Режим пар (новый):
┌─────────────┐
│  Getter 1   │────────┐
└─────────────┘        ├──> ТОЛЬКО STARLINK-1007
┌─────────────┐        │
│  Getter 2   │────────┘
└─────────────┘
   (Пара #1)

┌─────────────┐
│  Getter 3   │────────┐
└─────────────┘        ├──> ТОЛЬКО STARLINK-1008
┌─────────────┐        │
│  Getter 4   │────────┘
└─────────────┘
   (Пара #2)
```

## Структура JSON

```json
{
  "getterPairs": [                    ← Корневой объект
    {
      "pairId": "europe_link",       ← Уникальный ID пары
      "satelliteName": "STARLINK-1007", ← Точное имя спутника из TLE
      "getters": [                    ← Массив из 2 getter'ов
        {
          "name": "London Station",   ← Название станции
          "lon": -0.127,             ← Долгота
          "lat": 51.507              ← Широта
        },
        {
          "name": "Moscow Station",
          "lon": 37.617,
          "lat": 55.755
        }
      ]
    }
  ]
}
```

## Workflow (как это работает)

```
1. Пользователь загружает JSON файл
   │
   ├─> Система проверяет наличие поля "getterPairs"
   │
   ├─> ДА: Режим пар
   │   │
   │   ├─> Для каждой пары:
   │   │   │
   │   │   ├─> Создать 2 красных маркера на глобусе
   │   │   │
   │   │   ├─> Сохранить связь: пара ↔ спутник
   │   │   │
   │   │   └─> Добавить в массив getterPairs[]
   │   │
   │   └─> При каждом обновлении (каждую секунду):
   │       │
   │       ├─> Для каждой пары:
   │       │   │
   │       │   ├─> Найти спутник по имени
   │       │   │
   │       │   ├─> Проверить расстояние (<5000 км?)
   │       │   │
   │       │   ├─> Проверить луч (не сквозь Землю?)
   │       │   │
   │       │   └─> Нарисовать лучи от обоих getter'ов к спутнику
   │       │
   │       └─> Цвет луча = f(расстояние)
   │
   └─> НЕТ: Старый режим (обычные маркеры)
```

## Пример работы

### Шаг 1: Создаем JSON файл

```json
{
  "getterPairs": [
    {
      "pairId": "test_pair",
      "satelliteName": "STARLINK-1007",
      "getters": [
        { "name": "NY", "lon": -74.006, "lat": 40.713 },
        { "name": "LA", "lon": -118.243, "lat": 34.052 }
      ]
    }
  ]
}
```

### Шаг 2: Загружаем в приложение

1. Открываем приложение
2. Выбираем "Starlink" в списке созвездий
3. Нажимаем "Render"
4. В секции "Red Marker" нажимаем "Choose File"
5. Выбираем наш JSON файл
6. Нажимаем "Load Markers"

### Шаг 3: Результат

```
На глобусе появятся:
├─> 2 красных маркера (NY и LA)
├─> Если STARLINK-1007 в пределах 5000 км:
│   ├─> Луч от NY к STARLINK-1007
│   └─> Луч от LA к STARLINK-1007
└─> Цвет лучей зависит от расстояния
```

```

0 км     ████████████ Ярко-зеленый (rgb(0, 255, 0))
         
1000 км  ████████████ Желто-зеленый (rgb(51, 204, 0))

2000 км  ████████████ Желтый (rgb(102, 153, 0))

3000 км  ████████████ Оранжевый (rgb(153, 102, 0))

4000 км  ████████████ Красно-оранжевый (rgb(204, 51, 0))

5000 км  ████████████ Красный (rgb(255, 0, 0))

> 5000   (Луч не отображается)
```

## Отладка

### Проблема: Лучи не отображаются

Проверьте:
1. ✓ Выбрано созвездие, содержащее спутник
2. ✓ Нажата кнопка "Render"
3. ✓ Имя спутника точно совпадает (включая регистр)
4. ✓ Спутник в пределах 5000 км
5. ✓ Луч не проходит сквозь Землю

### Проблема: Маркеры не создаются

Проверьте JSON:
```javascript
// Правильно:
{
  "getterPairs": [           // ← массив
    {
      "pairId": "...",
      "getters": [            // ← массив из 2 элементов
        {...},
        {...}
      ]
    }
  ]
}

// Неправильно:
{
  "getterPairs": {           // ← НЕ объект, должен быть массив!
    "pairId": "...",
    "getters": {...}         // ← НЕ объект, должен быть массив!
  }
}
```
