# 🎯 Визуальное резюме в одной странице

## Главная формула

```
              ДОСТУПНОСТЬ СПУТНИКА
                      │
                      ▼
    ┌─────────────────────────────────────────┐
    │ расстояние = √(горизонт² + высота²)   │
    │                                         │
    │ Если ≤ 7000км → ✓ ДОСТУПЕН             │
    │ Если > 7000км  → ✗ НЕ ДОСТУПЕН        │
    └─────────────────────────────────────────┘
```

```
│     - Расстояние от Getter2                                     │

                           │
              ┌────────────┼────────────┐
              │            │            │
              ▼            ▼            ▼
         ┌────────┐   ┌────────┐   ┌──────────┐
         │ Оба    │   │Только  │   │ Только   │
         │ могут  │   │ Tokyo  │   │ Osaka    │

         │        │   │   ✗    │   │    ✗     │

    │  Красные = далеко (5500-7000км)        │
    └────────────────────────────────────────┘
```

## Пример расчета в деталях

```
ДАНО:
  Tokyo: lon=139.76, lat=35.68
  Спутник: lon=120.5, lat=40.2, height=550км

ШАГ 1: Haversine (горизонтальное расстояние)
  Δlon = 120.5 - 139.76 = -19.26°
  Δlat = 40.2 - 35.68 = 4.52°
  
  a = sin²(2.26°) + cos(35.68°)×cos(40.2°)×sin²(9.63°)
  a ≈ 0.030
  
  c = 2×atan2(√0.030, √0.970)
  c ≈ 0.351 радиан
  
  surface = 6371 × 0.351 ≈ 2236 км

ШАГ 2: Добавляем высоту спутника
  total = √(2236² + 550²)
  total = √(5000096 + 302500)
  total = √5302596
  total ≈ 2302.7 км

ШАГ 3: Проверка
  2302.7 км ≤ 7000 км?
  ДА! → ✓ ДОСТУПЕН
```

## Символы и их значения

```
G1  = Getter 1 (первая точка на земле)
G2  = Getter 2 (вторая точка на земле)
✓   = Доступен (расстояние ≤ 7000км)
✗   = Не доступен (расстояние > 7000км)
km  = километры
```

## Главное, что нужно помнить

```
┌─────────────────────────────────────────────────────────┐
│ ФОРМУЛА:                                                │
│ расстояние = √(горизонтальное² + высота спутника²)    │
│                                                         │
│ ПРОВЕРКА:                                              │
│ IF расстояние ≤ 7000 км THEN ✓ доступен               │
│                         ELSE ✗ недоступен             │
│                                                         │
│ РЕЗУЛЬТАТ:                                             │
│ - На консоли: логирование с расстояниями для каждого  │
│ - На карте: цветные линии от getter'ов к спутникам   │
│                                                         │
│ ЦВЕТА:                                                 │
│ 🟢 Зеленый = близко (0-3500 км)                       │
│ 🟡 Желтый = средне (3500-5500 км)                     │
│ 🔴 Красный = далеко (5500-7000 км)                    │
│                                                         │
│ Спутник доступен = есть линия                         │
│ Спутник недоступен = нет линии                        │
└─────────────────────────────────────────────────────────┘
```
