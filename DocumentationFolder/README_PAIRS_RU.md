# Краткая инструкция: Пары Getter'ов

## Что изменилось?

Теперь можно создавать **пары getter'ов** (наземных станций), которые работают **только со своим спутником**.

## Формат JSON файла

```json
{
  "getterPairs": [
    {
      "pairId": "pair1",
      "satelliteName": "STARLINK-1007",
      "getters": [
        {
          "name": "Getter 1",
          "lon": -74.006,
          "lat": 40.713
        },
        {
          "name": "Getter 2",
          "lon": -118.243,
          "lat": 34.052
        }
      ]
    }
  ]
}
```

## Ключевые моменты:

1. **`getterPairs`** - обязательное поле для нового формата
2. **`pairId`** - уникальное имя пары (например: "pair1", "europe_link")
3. **`satelliteName`** - ТОЧНОЕ имя спутника из TLE файла
4. **`getters`** - массив из РОВНО 2 станций

## Как это работает:

✅ Каждая пара работает ТОЛЬКО со своим спутником  
✅ Можно иметь несколько пар в одном файле  
✅ Каждая пара независима от других  
✅ Лучи рисуются только между парой и ее спутником  

## Файлы примеров:

- `spaceMy_pairs_example.json` - 3 пары getter'ов
- `test_one_pair.json` - 1 пара для тестирования

## Старый формат все еще работает:

```json
[
  {
    "name": "Point 1",
    "lon": -74.006,
    "lat": 40.713
  }
]
```

Система автоматически определит формат.
