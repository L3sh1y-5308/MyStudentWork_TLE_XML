# Обновление: Система пар Getter'ов

## Что было сделано

Добавлена новая функциональность для работы с **парами getter'ов** (наземных станций), которые работают вместе и подключаются только к определенному спутнику.

## Изменения в коде

### 1. Обновлен `services/Gettersline.js`

**Добавлены новые переменные:**
- `getterPairs` - массив для хранения пар getter'ов
- `pairIdCounter` - счетчик для уникальных ID пар

**Новые функции:**

#### `addGetterPairs(pairsData)`
Создает пары getter'ов из JSON данных. Каждая пара:
- Содержит ровно 2 getter'а
- Привязана к определенному спутнику по имени
- Работает независимо от других пар

```javascript
const pairs = addGetterPairs([
  {
    pairId: "pair1",
    satelliteName: "STARLINK-1007",
    getters: [
      { name: "Getter 1", lon: -74.006, lat: 40.713 },
      { name: "Getter 2", lon: -118.243, lat: 34.052 }
    ]
  }
]);
```

#### `getGetterPairs()`
Возвращает список всех созданных пар getter'ов.

#### `clearGetterPairs()`
Очищает все пары getter'ов.

#### `updateRaysForGetterPairs(satellites, maxDistance)`
Обновляет лучи (raycast) для пар getter'ов. Ключевые особенности:
- Каждая пара подключается ТОЛЬКО к своему спутнику
- Ищет спутник по точному имени (`satelliteName`)
- Рисует лучи от обоих getter'ов к их спутнику
- Проверяет расстояние и пересечение с Землей
- Цвет луча зависит от расстояния (зеленый=близко, красный=далеко)

**Обновлена функция:**
- `clearMarkers()` - теперь также очищает лучи и пары getter'ов

### 2. Обновлен `ui/marker_json_controls.js`

**Изменения в `initMarkerJsonControls()`:**
- Автоматическое определение формата JSON файла
- Поддержка нового формата с полем `getterPairs`
- Обратная совместимость со старым форматом (массив точек)

```javascript
// Новый формат с парами
if (data.getterPairs && Array.isArray(data.getterPairs)) {
  addGetterPairs(data.getterPairs);
}
// Старый формат
else {
  const points = normalizeMarkers(data);
  addMarkers(points);
}
```

**Обновлена функция `renderMarkerList()`:**
- Отображает пары getter'ов отдельно от обычных маркеров
- Показывает связь между парой и спутником
- Визуальное различие: пары выделены синим цветом, обычные маркеры - красным

### 3. Обновлен `services/satellites.js`

**Изменения в `updateSatellites()`:**
- Добавлена проверка наличия пар getter'ов
- Если пары существуют - используется `updateRaysForGetterPairs()`
- Если пар нет - используется старая `updateRaysToMarker()`

```javascript
const pairs = getGetterPairs();
if (pairs.length > 0) {
  updateRaysForGetterPairs(allVisibleSatellites, 5000);
} else {
  updateRaysToMarker(allVisibleSatellites, 5000);
}
```

## Формат JSON файла

### Новый формат (с парами)

```json
{
  "getterPairs": [
    {
      "pairId": "pair1",
      "satelliteName": "STARLINK-1007",
      "getters": [
        {
          "name": "Getter New York",
          "lon": -74.006,
          "lat": 40.713
        },
        {
          "name": "Getter Los Angeles",
          "lon": -118.243,
          "lat": 34.052
        }
      ]
    },
    {
      "pairId": "pair2",
      "satelliteName": "STARLINK-1008",
      "getters": [
        {
          "name": "Getter London",
          "lon": -0.127,
          "lat": 51.507
        },
        {
          "name": "Getter Paris",
          "lon": 2.352,
          "lat": 48.856
        }
      ]
    }
  ]
}
```

### Старый формат (обратная совместимость)

```json
[
  {
    "name": "Modem New York",
    "lon": -74.006,
    "lat": 40.713
  }
]
```

## Как использовать

1. Откройте приложение
2. Выберите созвездие (например, Starlink)
3. Нажмите "Render"
4. Загрузите JSON файл с парами через интерфейс
5. Система автоматически:
   - Создаст красные маркеры для всех getter'ов
   - Найдет спутники по имени
   - Нарисует лучи ТОЛЬКО между парами и их спутниками

## Ключевые особенности

✅ **Изоляция пар** - каждая пара работает только со своим спутником  
✅ **Множественные пары** - можно иметь несколько пар в одном файле  
✅ **Независимость** - пары не мешают друг другу  
✅ **Обратная совместимость** - старые JSON файлы работают как прежде  
✅ **Автоопределение формата** - система сама определяет тип файла  
✅ **Визуальная обратная связь** - разные цвета для пар и обычных маркеров  

## Требования

- Каждая пара должна содержать РОВНО 2 getter'а
- Имя спутника должно ТОЧНО совпадать с именем в TLE файле
- Координаты должны быть валидными (lat: -90 до 90, lon: -180 до 180)

## Что делать если не работает

1. Проверьте формат JSON файла
2. Убедитесь что `satelliteName` точно совпадает с именем в TLE
3. Проверьте что выбрано правильное созвездие и нажата кнопка "Render"
4. Убедитесь что спутник находится в пределах 5000 км от getter'ов
5. Проверьте что луч не проходит сквозь Землю
