# Логика расчета доступности спутников для пар Getter'ов

## Как система определяет, дотягивается ли getter к спутнику

### Формула расчета расстояния

Используется **формула Хаверсина** для расчета расстояния по поверхности Земли + добавляется высота спутника.

```
1. Расстояние по поверхности земли:
   - Берутся координаты getter'а (lat1, lon1)
   - Берутся координаты спутника (lat2, lon2)
   - Рассчитывается "дугообразное" расстояние

2. Добавляется высота спутника:
   - Спутник находится на высоте h км над поверхностью
   - Итоговое расстояние = √(расстояние_по_земле² + высота²)

3. Сравнение с максимальным расстоянием:
   - Если расстояние ≤ 7000 км → ✓ ДОСТУПЕН
   - Если расстояние > 7000 км → ✗ НЕ ДОСТУПЕН
```

### Пример расчета

```
Getter A в Лондоне:        (lon: -0.127, lat: 51.507)
Спутник STARLINK-1019:     (lon: 10.0, lat: 45.0, height: 550km)

1. Расстояние по поверхности = ~1150 км
2. Добавляем высоту спутника = √(1150² + 550²) = ~1278 км
3. 1278 км ≤ 7000 км → ✓ ДА, Getter A может дотянуться

Getter B в Токио:          (lon: 139.691, lat: 35.689)
1. Расстояние по поверхности = ~9500 км
2. Добавляем высоту спутника = √(9500² + 550²) = ~9516 км
3. 9516 км > 7000 км → ✗ НЕТ, Getter B не может дотянуться
```

## Приоритет выбора спутника

### Сценарий 1: Есть общий спутник

```
Getter A может дотянуться до STARLINK-1019 ✓
Getter B может дотянуться до STARLINK-1019 ✓
      ↓↓↓
ОБА getter'а рейкастят ТОЛЬКО в STARLINK-1019
Другие спутники ИГНОРИРУЮТСЯ до тех пор,
пока есть доступный общий спутник
```

### Сценарий 2: Нет общего спутника

```
Getter A может дотянуться до: STARLINK-1019 (4000km), STARLINK-1020 (5500km)
Getter B может дотянуться до: STARLINK-1021 (6500km), STARLINK-1022 (6800km)
      ↓↓↓
Getter A рейкастит в ближайший: STARLINK-1019 (4000km)
Getter B рейкастит в ближайший: STARLINK-1021 (6500km)
Каждый рейкастит в СВОЙ ближайший спутник
```

## Как читать консольные логи

### Формат логирования

```
[updateRaysForGetterPairs] ===== PAIR: japan_pair =====
[updateRaysForGetterPairs] Getter1: "Tokyo" at (139.691, 35.689)
[updateRaysForGetterPairs] Getter2: "Osaka" at (135.506, 34.674)
[updateRaysForGetterPairs] Max distance: 7000km
```

### Доступные спутники

```
  "STARLINK-1019": G1:✓ 4523km | G2:✗ 5200km
  "STARLINK-1020": G1:✓ 3821km | G2:✓ 4100km
  "STARLINK-1021": G1:✗ 7500km | G2:✗ 7800km
  "STARLINK-1022": G1:✗ 8200km | G2:✗ 8500km
```

**Значение:**
- `✓` - getter может дотянуться (расстояние ≤ 7000 км)
- `✗` - getter НЕ может дотянуться (расстояние > 7000 км)

### Итоги

```
[updateRaysForGetterPairs] Processed: 2500 satellites
[updateRaysForGetterPairs] Accessible: 147
[updateRaysForGetterPairs] Common: 5, G1 only: 3, G2 only: 2
```

**Означает:**
- Всего спутников: 2500
- Из них доступны: 147
- Из доступных:
  - 5 общих (оба могут дотянуться)
  - 3 только для Getter1
  - 2 только для Getter2

## Почему спутник недоступен

### Причина 1: Слишком далеко

```
Getter в Лондоне (lon: -0.127, lat: 51.507)
Спутник над Австралией (lon: 151.2, lat: -33.9)
Расстояние = ~17000 км > 7000 км
→ ✗ НЕ ДОСТУПЕН (слишком далеко)
```

### Причина 2: На другой стороне Земли

```
Getter на экваторе (lat: 0)
Спутник на противоположной стороне Земли
Расстояние = ~20000+ км
→ ✗ НЕ ДОСТУПЕН
```

### Причина 3: Луч проходит сквозь Землю

Даже если расстояние в пределах лимита, луч может быть заблокирован:

```
Getter в Лондоне
Спутник на орбите над противоположной стороной Земли
Луч: Лондон → [земля в пути] → Спутник
→ ✗ НЕ ДОСТУПЕН (пересекает Землю)
```

## Как увеличить количество доступных спутников

### Способ 1: Увеличить maxDistance

Текущее значение: **7000 км**

Измените в `satellites.js`:
```javascript
updateRaysForGetterPairs(allVisibleSatellites, 10000);  // Увеличить до 10000 км
```

### Способ 2: Расположить getter'ы на экваторе

На экваторе больше спутников на низкой орбите:
```json
{
  "pairId": "equator_pair",
  "getters": [
    {"name": "Getter1", "lon": 0, "lat": 0},      // На экваторе
    {"name": "Getter2", "lon": 20, "lat": 0}      // На экваторе
  ]
}
```

### Способ 3: Расположить getter'ы ближе друг к другу

Если getter'ы на расстоянии 1000 км:
```json
{
  "getters": [
    {"lon": 0, "lat": 45},
    {"lon": 10, "lat": 45}      // Близко к первому
  ]
}
```

## Проверка в браузере

1. Откройте **F12 → Console**
2. Загрузите JSON с парами
3. Смотрите логи:

```
[updateRaysForGetterPairs] ===== PAIR: japan_pair =====
[updateRaysForGetterPairs] Getter1: "Tokyo" at (139.691, 35.689)
[updateRaysForGetterPairs] Processed: 2500 satellites, Accessible: 147
[updateRaysForGetterPairs] Common: 5, G1 only: 3, G2 only: 2
  "STARLINK-1019": G1:✓ 4523km | G2:✗ 5200km
  "STARLINK-1020": G1:✓ 3821km | G2:✓ 4100km
  ...
[updateRaysForGetterPairs] Using COMMON satellites mode
  Getter1 → "STARLINK-1020" 
  Getter2 → "STARLINK-1020"
```

**Что это означает:**
- Обнаружено 5 общих спутников
- Они рейкастят в близкий STARLINK-1020 (оба могут дотянуться)
- Система выбрала режим "COMMON satellites"
