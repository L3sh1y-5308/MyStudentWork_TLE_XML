## Пошаговый расчет для одного спутника

### Пример: STARLINK-1020

```
ДАНО:
  Getter1 (Tokyo):    lon=139.76, lat=35.68
  Getter2 (Osaka):    lon=135.50, lat=34.73
  Спутник STARLINK-1020:
    - lon = 120.5
    - lat = 40.2
    - высота = 550 км
  Max Distance = 7000 км

ШАГИ РАСЧЕТА:

[ШАГ 1] Расчет расстояния Tokyo → STARLINK-1020
┌─────────────────────────────────────────┐
│ Координаты:                              │
│ Tokyo: (139.76°E, 35.68°N)              │
│ Спутник: (120.5°E, 40.2°N)              │
├─────────────────────────────────────────┤
│ Разница в широте:     40.2 - 35.68 = 4.52° │
│ Разница в долготе:   120.5 - 139.76 = -19.26° │
├─────────────────────────────────────────┤
│ Формула Haversine:                      │
│ a = sin²(Δlat/2) +                      │
│     cos(lat1)×cos(lat2)×sin²(Δlon/2)   │
│                                          │
│ a = sin²(2.26°) +                       │
│     cos(35.68°)×cos(40.2°)×sin²(-9.63°) │
│                                          │
│ a ≈ 0.0154 + 0.6676×0.7685×0.0283      │
│ a ≈ 0.0154 + 0.0145                    │
│ a ≈ 0.0299                              │
├─────────────────────────────────────────┤
│ c = 2×atan2(√a, √(1-a))                │
│ c = 2×atan2(0.1729, 0.9849)            │
│ c ≈ 0.3511 радиан ≈ 20.1°              │
├─────────────────────────────────────────┤
│ Расстояние по поверхности:              │
│ d = R × c = 6371 × 0.3511               │
│ d ≈ 2236 км                             │
├─────────────────────────────────────────┤
│ Добавляем высоту спутника (550км):      │
│ total = √(2236² + 550²)                │
│ total = √(5000096 + 302500)            │
│ total = √5302596                        │
│ total ≈ 2302.7 км                       │
├─────────────────────────────────────────┤
│ РЕЗУЛЬТАТ:                               │
│ 2302.7 км ≤ 7000 км → ✓ ДОСТУПЕН       │
└─────────────────────────────────────────┘

[ШАГ 2] Расчет расстояния Osaka → STARLINK-1020
┌─────────────────────────────────────────┐
│ Координаты:                              │
│ Osaka: (135.50°E, 34.73°N)              │
│ Спутник: (120.5°E, 40.2°N)              │
├─────────────────────────────────────────┤
│ Разница в широте:     40.2 - 34.73 = 5.47° │
│ Разница в долготе:   120.5 - 135.50 = -15° │
├─────────────────────────────────────────┤
│ ... (аналогичный расчет Haversine) ...  │
│                                          │
│ Расстояние по поверхности ≈ 1500 км    │
│ total = √(1500² + 550²)                │
│ total ≈ 1600 км                         │
├─────────────────────────────────────────┤
│ РЕЗУЛЬТАТ:                               │
│ 1600 км ≤ 7000 км → ✓ ДОСТУПЕН         │
└─────────────────────────────────────────┘

[ИТОГ ДЛЯ СПУТНИКА]
  STARLINK-1020:
  - Tokyo:  ✓ 2302.7 км (можно дотянуться)
  - Osaka:  ✓ 1600.0 км (можно дотянуться)
  → ЭТОТ СПУТНИК ОБЩИЙ для обеих точек
  → Он попадет в Common Satellites список
```

## Цветовая кодировка линий (лучей)

```
Расстояние    | Цвет RGB      | Линия                  | Интерпретация
──────────────┼───────────────┼────────────────────────┼─────────────────
0 км          | (0, 255, 0)   | ЗЕЛЕНА ████████████     | Спутник над гетером
1000 км       | (0, 255, 0)   | ЗЕЛЕНА ████████████     | Очень близко
3500 км       | (128, 128, 0) | ЖЕЛТАЯ ████████████     | Средне близко  
5000 км       | (255, 128, 0) | ОРАНЖЕВА ████████████   | Далеко
6500 км       | (255, 32, 0)  | КРАСНА ████████████     | Очень далеко
7000 км       | (255, 0, 0)   | КРАСНА ████████████     | На краю лимита
```

Формула цвета:
```
ratio = расстояние / maxDistance (7000 км)
красный (R) = 255 × ratio
зеленый (G) = 255 × (1 - ratio)
синий (B) = 0
```

## Примеры расчетов на разных расстояниях

### Сценарий 1: Getter'ы близко (100 км)

```
Tokyo (0, 0) ←→ Osaka (100км) ←→ Спутник над экватором
                                 (2000км дальше от Osaka)

Tokyo → Спутник:
  Горизонтально: 2100 км
  Высота: 550 км
  Итого: √(2100² + 550²) = 2173 км ✓

Osaka → Спутник:
  Горизонтально: 2000 км
  Высота: 550 км
  Итого: √(2000² + 550²) = 2073 км ✓

РЕЗУЛЬТАТ: ОБЩИЙ спутник ✓
```

### Сценарий 2: Getter'ы далеко (8000 км)

```
Tokyo (lon:0) ←──────────────────────→ Москва (lon:180km)
                                         |
                                    Спутник над Атлантикой

Tokyo → Спутник:
  Горизонтально: 8000 км (уже на краю!)
  Высота: 550 км
  Итого: √(8000² + 550²) = 8018 км ✗ (> 7000км)

Москва → Спутник:
  Горизонтально: 1000 км
  Высота: 550 км
  Итого: √(1000² + 550²) = 1135 км ✓

РЕЗУЛЬТАТ: Только Москва может дотянуться (индивидуальный режим)
```

### Сценарий 3: Спутник на противоположной стороне

```
Tokyo (lon:140°E) ←──────────────────────────→ Спутник (lon:140°W)
                     20000 км
                   (через земной диаметр)

Tokyo → Спутник:
  Горизонтально: 20000 км ✗
  Высота: 550 км
  Итого: √(20000² + 550²) = 20007 км ✗ (WAY > 7000км)

РЕЗУЛЬТАТ: Спутник НЕ доступен ни для кого
```

## Почему нужна высота спутника в формуле?

```
СЛУЧАЙ 1: Спутник прямо над getter'ом
┌─────────────────────┐
│    СПУТНИК          │ 550 км
│       (●)           │
├─────────────────────┤
│   ЗЕМЛЯ (радиус)    │ 6371 км
│      (●) GETTER     │
└─────────────────────┘

Горизонтальное расстояние: 0 км
Высота спутника: 550 км
Итого: √(0² + 550²) = 550 км ✓


СЛУЧАЙ 2: Спутник на горизонте
     СПУТНИК (●) 550км выше экватора
        ╱      ╲
      ╱          ╲
    ╱              ╲
   │                │ 
   │   ЗЕМЛЯ        │ 6371 км
   │   (●) GETTER   │
    ╲              ╱
      ╲          ╱
        ╲      ╱
        
Горизонтальное расстояние: ~7000 км
Высота спутника: 550 км
Итого: √(7000² + 550²) = 7021 км ✗ (НА КРАЮ ЛИМИТА)


ПОЧЕМУ?
Спутник не находится на земной поверхности!
Он в космосе, на высоте 550 км.
Луч идет НЕ по земле, а в 3D пространстве.
Поэтому используем пифагорову теорему.
```
