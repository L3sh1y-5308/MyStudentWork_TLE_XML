## Быстрый старт / Quick Start

### 1. Откройте приложение
Запустите `index.html` в браузере

### 2. Загрузите сценарий
1. Откройте боковую панель (кнопка меню ≡)
2. Прокрутите до раздела **"Scenario Mode"** (оранжевый заголовок)
3. Нажмите **"Choose File"** → выберите `data/example_scenarios.json`
4. Сценарии загрузятся в выпадающий список

### 3. Активируйте сценарий
1. Выберите сценарий (например, "Kiev Station Coverage")
2. Нажмите **"Activate Selected Scenario"**
3. Система автоматически:
   - ✅ Создаст геттер на карте
   - ✅ Установит дату и время из JSON
   - ✅ Загрузит созвездия (Starlink, OneWeb)
   - ✅ Включит режим сценариев

### 4. Настройте время для тестирования
В разделе **"Time"**:
1. Измените время на 12:00 (или другое время из вашего сценария)
2. Отрендерите созвездия **Starlink** и **OneWeb** (кнопка "Render")
3. Включите треки (галочка "Trails")

### 5. Наблюдайте за сценарием
- **Активный спутник** будет увеличен в 3 раза с золотистым треком
- **Панель статуса** покажет текущее состояние окна
- Используйте кнопки **"+5 min"** для быстрого тестирования окон

## Структура сценария / Scenario Structure

```json
{
  "name": "Название",
  "date": "2026-02-17",
  "startTime": "12:00",
  "constellations": ["Starlink", "OneWeb"],
  "getterPoint": { "lon": 30.5, "lat": 50.4, "name": "Станция" },
  "windows": [
    {
      "satelliteName": "STARLINK-1007",
      "constellationName": "Starlink",
      "startTime": "12:00",
      "endTime": "12:55",
      "color": "#00ff00"
    }
  ],
  "safetyWindow": 5
}
```

**🆕 Новые поля:**
- `date` - Дата сценария (YYYY-MM-DD)
- `startTime` - Время начала для автоустановки (HH:MM)
- `constellations` - Массив созвездий для автозагрузки

## Статусы окон / Window Statuses

| Статус | Цвет | Описание |
|--------|------|----------|
| **ACTIVE** | 🟢 Зеленый | Спутник виден прямо сейчас |
| **SAFETY WINDOW** | 🟠 Оранжевый | Промежуток между окнами (5 мин) |
| **WAITING** | 🔵 Синий | Ожидание следующего спутника |
| **NO ACTIVE WINDOW** | ⚫ Серый | Все окна завершены |

## Создание своего сценария / Create Your Own

1. Скопируйте `data/example_scenarios.json`
2. Измените координаты `getterPoint`
3. Измените `satelliteName` (проверьте точное имя в TLE)

5. Загрузите через UI

## Советы / Tips

💡 **Поиск имен спутников**: Откройте TLE файл (например, `data/starlink.tle`) - имя спутника в первой строке

💡 **Быстрое тестирование**: Используйте кнопки **"-5 min"** / **"+5 min"** для перемещения по окнам

💡 **Окна безопасности**: Рекомендуется 5-10 минут между окнами

💡 **Множественные созвездия**: Можно комбинировать Starlink, OneWeb, GPS в одном сценарии

## Устранение проблем / Troubleshooting

**❌ Спутник не подсвечивается:**
- Проверьте точное имя (регистр важен!)
- Убедитесь что созвездие отрендерено
- Проверьте время в окне

**❌ Сценарий не загружается:**
- Проверьте JSON синтаксис на [jsonlint.com](https://jsonlint.com)
- Убедитесь в наличии всех обязательных полей

**❌ Статус не обновляется:**
- Включите "Scenario Mode"
- Активируйте сценарий
