# 📋 Полный ответ на вопрос: "Как система определяет доступность спутников?"

## Главный ответ в одном предложении:

**Система вычисляет расстояние от getter'а до спутника по формуле `√(горизонтальное_расстояние² + высота_спутника²)` и если результат ≤ 7000км, спутник доступен (✓), иначе недоступен (✗).**

## Пошаговое объяснение алгоритма

```
INPUT:
  Getter1: lon=139.76, lat=35.68 (Tokyo)
  Getter2: lon=135.50, lat=34.73 (Osaka)
  Спутник: lon=120.5, lat=40.2, height=550км
  Max Distance: 7000км

PROCESS:

┌─ ДЛЯ КАЖДОГО СПУТНИКА ─┐
│                        │
├─ Шаг 1: Haversine     │
│  Расчет горизонтального расстояния по земной поверхности
│  Tokyo → Спутник ≈ 2236км
│  Osaka → Спутник ≈ 1500км
│
├─ Шаг 2: Добавить высоту
│  Tokyo: √(2236² + 550²) = 2302км
│  Osaka: √(1500² + 550²) = 1600км
│
├─ Шаг 3: Проверить лимит
│  Tokyo: 2302км ≤ 7000км? → ✓ ДА
│  Osaka: 1600км ≤ 7000км? → ✓ ДА
│
└─ РЕЗУЛЬТАТ: ОБЩИЙ СПУТНИК ✓ (оба могут дотянуться)


LOGIC:
  IF оба могут дотянуться → РЕЖИМ COMMON
    Оба getter'а рейкастят в ОДИН спутник
    
  ELSE IF хотя бы один может → РЕЖИМ INDIVIDUAL
    Каждый getter рейкастит в свой ближайший спутник
    
  ELSE → Нет доступных спутников
    На карте нет линий


OUTPUT:
  На карте появляются цветные линии (полилинии)
  - От Tokyo к спутнику(ам)
  - От Osaka к спутнику(ам)
  - Цвет: зеленый (близко) → красный (далеко)

  В консоли логируются все расчеты:
  [updateRaysForGetterPairs] Common: 5, G1 only: 50, G2 only: 45
```

## Формула в математическом виде

### Haversine Formula (расстояние по земной поверхности)

```
R = 6371 км (радиус Земли)
a = sin²(Δlat/2) + cos(lat1)·cos(lat2)·sin²(Δlon/2)
c = 2·atan2(√a, √(1-a))
d_surface = R·c
```

### Итоговое расстояние (с высотой спутника)

```
d_total = √(d_surface² + h²)

где:
  d_surface = расстояние по земной поверхности (км)
  h = высота спутника над поверхностью (км, обычно 550)
  d_total = итоговое расстояние от getter'а до спутника (км)
```

### Проверка доступности

```
IF d_total ≤ 7000 км THEN
  спутник ✓ ДОСТУПЕН (показать зеленую/желтую линию)
ELSE
  спутник ✗ НЕ ДОСТУПЕН (не показывать линию)
END IF
```
