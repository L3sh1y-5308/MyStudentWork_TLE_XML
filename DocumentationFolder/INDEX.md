## 🎬 Видеоподсказки (в виде текста)

### Как работает система (в 30 секунд)

```
ВЫ ЗАГРУЖАЕТЕ JSON С ДВУМЯ GETTER'АМИ
          ↓
СИСТЕМА БЕРЕТ КАЖДОГО СПУТНИКА (2500 шт)
          ↓
ДЛЯ КАЖДОГО СПУТНИКА:
  - Вычисляет расстояние от Getter1 (по Haversine + высота)
  - Вычисляет расстояние от Getter2 (по Haversine + высота)
  - Проверяет: обе расстояния ≤ 7000км?
    - ДА → спутник ОБЩИЙ (оба могут)
    - НЕТ → спутник ИНДИВИДУАЛЬНЫЙ (только один может)
          ↓
ВЫБОР РЕЖИМА:
  - Если есть общие → оба рейкастят в них
  - Иначе → каждый в свой ближайший
          ↓
ВИЗУАЛИЗАЦИЯ:
  - Рисует цветные линии (лучи) от getter'ов к спутникам
  - Зеленые = близко, красные = далеко
  - Логирует все расчеты в консоль
```

## ⚡ Быстрая справка по формулам

### Расстояние по земной поверхности (Haversine)
```
surface = R × 2×atan2(√a, √(1-a))
где a = sin²(Δlat/2) + cos(lat1)×cos(lat2)×sin²(Δlon/2)
R = 6371 км (радиус Земли)
```

### Итоговое расстояние
```
total = √(surface² + height²)
```

### Проверка доступности
```
IF total ≤ 7000 км THEN ✓ ДОСТУПЕН ELSE ✗ НЕ ДОСТУПЕН
```
